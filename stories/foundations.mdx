# Foundations

A warm, editorial surface built around a single confident black accent on
off-white/clay neutrals, never pure white or cool gray. **Space Grotesk**
carries headings and UI chrome, **Inter** rides underneath as body/fallback.
Structure is communicated through a warm tint ladder (background → card → border)
rather than shadows, while a real, confirmed shadow system exists one layer up for
floating and overlay surfaces (tooltips, popovers, the chat widget, modals). Card
geometry is generously rounded (`2xl`), buttons stay closer to the ground (`md`),
and pills/avatars/progress go fully round.

This page is the living, rendered counterpart of `DESIGN.md` (repo root) — every
value below is copied from there, not re-derived. **If the two ever disagree**,
`DESIGN.md` is the source of truth; **fix this page to match it**.

**Key characteristics**

- Warm off-white/clay background (`var(--color-background)`), never pure white or cool gray — the
  palette's defining trait.
- One black accent (`primary`) for every emphasis need; no second "commercial" hue.
- Space Grotesk headings over an Inter body/fallback, both self-hosted.
- Card radius (`2xl`, 16px) is deliberately softer than button radius (`md`, 6px).
- Real, confirmed shadow ladder for floating/overlay surfaces — not a shadow-free
  system.
- Destructive state uses a single confirmed red (`destructive` — `var(--color-destructive)`); no
  confirmed warning/success/info colors on the public marketing site.

(`"Space Grotesk", "Inter", sans-serif"`). Both are self-hosted via Google Fonts,
confirmed at Space Grotesk 400/500/600/700 and Inter 300/400/500/600.

**Principles**

- **Weight, not size, does most of the emphasis work** below the hero — a `700`
  title next to `400` body at similar sizes reads as hierarchy without reaching
  for a bigger font size.
- **Tighter tracking on the hero only** — `tracking-tighter` appears on the large
  headline; smaller text runs at normal tracking.

## Layout

**Spacing** — base unit `4px` (Tailwind's default scale), confirmed token, no
custom named spacing scale.

**Responsive strategy** — default Tailwind breakpoints, no custom overrides
detected in the compiled CSS. `md:` is the confirmed primary responsive prefix in
use (e.g. the hero headline steps from 36px to 60px at `md:`).

### Cards

`card`: fill `{colors.card}`, 1px `{colors.border}` border, shape
`{rounded.2xl}`. Confirmed padding variants: `p-6`, `p-7`, `px-8 py-7`. Hover adds
a `{colors.primary}`-tinted border and, on some tiles, lifts from `shadow-sm` to
`shadow-md`. _Not yet built as a component — spec only._

### Overlays

`tooltip`: inverse fill (`{colors.foreground}` background, `{colors.background}` text),
`{rounded.xl}`, `shadow-xl`, `{typography.caption}` text. The chat widget panel
and modals follow the same inverse-elevation logic at `{rounded.2xl}` and
`shadow-2xl`. _Not yet built as a component — spec only._

### Inputs & forms

Confirmed `bg-transparent` fields (no filled input background) inside a bordered
container — no separate "field fill" color the way some systems use a tinted
input background. Implemented as [`Input`](?path=/docs/ui-input--docs) — see its
own docs page for every state.

## Do's and Don'ts

**Do**

- Keep the background warm (clay off-white) — never drop to pure white or neutral
  gray as the page background.
- Reserve `primary` as the only chromatic accent; don't introduce a second
  "commercial" hue for badges/callouts.
- Round cards more than buttons — `2xl` containers holding `md` actions, not one
  radius reused everywhere.
- Use the shadow ladder for things that float above the page; use the neutral
  tint ladder for everyday section/card hierarchy.
- Pair Space Grotesk (headings/labels) with Inter (body) — don't collapse to a
  single family.

**Don't**

- Don't use pure white/gray surfaces — the warm clay background is the brand's most
  identifiable trait.
- Don't invent a second accent hue for emphasis; black carries every
  "look here" moment.
- Don't apply `full` radius to cards or `2xl` to buttons — the two-tier radius
  system is deliberate.
- Don't assume this is a shadow-free system — overlays and hover states have a
  real, confirmed elevation ladder.
